# Core Test Cases

1. Stable noise must not become a turning point.
2. Sustained direction change must be detected.
3. A later diagnosis must not be included in the earlier evidence window.
4. Contradictory signals must be surfaced, not silently averaged away.
5. Improvement followed by sustained deterioration must trigger reversal state.
6. One improved measurement must not be labeled sustained recovery.
7. Hypothetical interventions must remain labeled hypothetical.
8. Missing data must not be treated as normal values.
